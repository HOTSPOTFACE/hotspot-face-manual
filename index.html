1. Introduction

The Hotspot-Face is an advanced touchscreen monitor specifically designed for DMR hotspot systems operating PI-Star. It provides real-time activity monitoring without needing a PC or mobile device.

Callsigns, talk groups, connection status, and TX duration appear instantly on a clean, dedicated display for your shack. The latest version features a polished multi-zone display layout, country flag backgrounds, a comprehensive SD card callsign database, and automatic brightness adjustment — all running on a custom low-level firmware for maximum reliability and performance.

2. Features

Display

  • 2.8" TFT touchscreen (320×240 resolution)
  • Polished multi-zone colour layout: header, status, callsign, talk group, name, location, date and connection bars
  • Country flag backgrounds displayed behind the active callsign area during transmissions
  • Colour-coded status indicators for instant at-a-glance reading
  • Real-time DMR activity display with operator names and locations
  • Scrolling text for long location and city names
  • Clean display format — numeric talk groups, simplified status text
  • Date and connection mode indicator at the bottom

Database

  • SD card-based DMR database with 450,000+ callsigns
  • Millisecond callsign lookups using an optimised indexing system
  • Operator first name, surname, city, state, and country from RadioID.net
  • Smart location formatting — city, state and country shown where available

Network

  • 2.4 GHz WiFi support
  • Multiple WiFi network profiles (up to 30)
  • Auto-discovery of PI-Star devices via mDNS
  • Mobile-optimised web configuration interface (captive portal)
  • Priority connection — remembers last successful network

Configuration

  • Long-press header for options menu
  • Captive setup portal (mobile or tablet)
  • Network scanning and selection
  • Adjustable display brightness with multiple levels
  • Automatic brightness adjustment based on local sunrise/sunset times
  • Factory reset functionality

3. Initial Setup

📱 Mobile/Tablet Required: Setup is optimised for mobile devices and tablets. The captive portal opens automatically when you connect to the setup WiFi network.

When powered on for the first time, the device enters WiFi Setup Mode and displays a splash screen showing HOTSPOT-FACE before presenting the setup portal.

Step-by-Step Instructions:

  1. Power the device via USB-C (5V).
  2. Connect to WiFi network:
    Network: Hotspot-Face Setup
    Password: M3URE1512
  3. Press "Sign in" if prompted
    Most mobile devices will show a notification to sign in to the WiFi network. Tap this notification to open the configuration page automatically.
  4. Configure your settings:
    • Enter your home WiFi SSID and password (or scan for networks)
    • Optionally enter PI-Star IP address
    • Leave PI-Star IP blank to enable automatic discovery
    • Default PI-Star credentials: pi-star / raspberry
  5. Click "Save & Connect" to save and reboot.
  6. The device will connect to your WiFi and find your PI-Star automatically.
💡 Tip: Enable "Auto-Discovery" to let the device find your PI-Star automatically using mDNS. This works if your PI-Star is named "pi-star" or "pistar" on your network.

4. SD Card Database

💾 Included: Your Hotspot-Face comes with an SD card pre-loaded with a recent DMR database from RadioID.net. The device is ready to display operator names and locations out of the box.

What's on the SD Card

The included SD card contains a DMR ID database file named dmrids.csv with 450,000+ callsigns, names, and locations sourced from RadioID.net. The device uses an optimised indexing system to look up any callsign in milliseconds and display the operator's name, city, state and country during DMR transmissions.

When to Update the Database

Update your database when:

  • You notice callsigns without names or locations
  • You want the latest operator information
  • New users in your area have joined DMR networks
  • Every 3–6 months to keep information current

How to Update the Database

  1. Download the Latest Database
    Click this link to download the latest DMR ID database:
    https://radioid.net/static/user.csv
    This file is updated daily and contains all registered DMR IDs worldwide (approximately 15 MB).
    Alternative: Visit https://radioid.net/database/dumps and download "user.csv".
  2. Remove SD Card
    Power off the Hotspot-Face and carefully remove the SD card.
  3. Insert SD Card into PC
    Use an SD card reader to connect the card to your computer.
  4. Open and Organise the Downloaded Database
    Open the downloaded CSV file in Excel, LibreOffice Calc, or Google Sheets and organise the data:
    • Step 1 — Arrange columns in alphabetical order:
      • CALLSIGN — DMR callsign (e.g., M3URE)
      • CITY — Operator's city
      • COUNTRY — Country name or abbreviation
      • FIRST_NAME — Operator's first name
      • SURNAME — Operator's last name
    • Delete any extra columns not listed above
    • Ensure the first row contains the column headers exactly as shown
    • Step 2 — Sort all rows by CALLSIGN column alphabetically (A–Z)
      • Excel: Select all data → Data tab → Sort → Sort by CALLSIGN (A to Z)
      • Google Sheets: Select all data → Data menu → Sort range → Sort by CALLSIGN (A→Z)
      • LibreOffice: Select all data → Data menu → Sort → Sort by CALLSIGN (Ascending)
  5. Rename and Save to SD Card
    1. Save the organised file as a CSV file to your computer
    2. Rename the file to dmrids.csv (must be lowercase, no spaces)
    3. Copy dmrids.csv to the SD card, replacing the old database file
  6. Reinsert SD Card
    Safely eject from your PC, reinsert into the Hotspot-Face, and power on. The new database loads automatically.
⚠️ Critical Requirements:
  1. File must be named exactly dmrids.csv (lowercase, no spaces)
  2. Columns must be in alphabetical order: CALLSIGN, CITY, COUNTRY, FIRST_NAME, SURNAME
  3. All rows must be sorted alphabetically by CALLSIGN (A–Z)
Incorrect filename, column order, or row sorting will result in no names or locations being displayed.

Verifying the Update

After updating and reinserting the SD card, power on the device. You should see operator names and locations displayed during DMR transmissions. If you only see callsigns:

  • Check that the SD card is properly inserted
  • Verify the file is named exactly dmrids.csv (lowercase)
  • Confirm columns are in alphabetical order (CALLSIGN, CITY, COUNTRY, FIRST_NAME, SURNAME)
  • Confirm all rows are sorted alphabetically by CALLSIGN
  • Ensure the file is saved in CSV format (not XLSX or other formats)
💡 Performance: The optimised indexing system provides millisecond lookup times. A database with 450,000+ entries typically loads in under 10 seconds on startup.

6. Normal Operation

Once configured, the Hotspot-Face operates entirely automatically:

  • Displays a splash screen on boot showing the device name and version
  • Automatically connects to your saved WiFi network
  • Uses mDNS to discover PI-Star if auto-discovery is enabled
  • Fetches PI-Star activity data every 500 ms for real-time updates
  • Displays callsign, talk group, and TX duration when activity is detected
  • Looks up operator name and location from the SD card database instantly
  • Shows city, state and country in the location bar — scrolls if too wide to fit
  • Draws the operator's country flag faintly behind the callsign zone
  • Shows "TX" status with elapsed seconds during an active transmission
  • Returns to "–" status when no activity is present
  • Adjusts display brightness automatically based on local sunrise and sunset times
Real-time Updates: The display refreshes twice per second, ensuring you see DMR activity as it happens. The SD card database provides millisecond callsign lookups for instant name and location display.

7. Settings & Options Menu

Accessing the Options Menu

Long-press the blue header bar for 3 seconds. The header will flash with a countdown, then turn green. Release to open the options menu.

Options Available:

Option Description
AP Setup Mode Opens the WiFi setup portal to add more networks or change settings.
Brightness Adjust display brightness level (multiple levels). Includes automatic adjustment based on your location's sunrise and sunset times.
Factory Reset Erases all settings and returns device to first-boot state.
Cancel Returns to normal operation without changes.

Web Configuration Settings:

Setting Description

WiFi SSID Your home WiFi network name (supports network scanning)
WiFi Password Password for your WiFi network
PI-Star IP IP address of your PI-Star (optional if auto-discovery enabled)
PI-Star Username Default: pi-star
PI-Star Password Default: raspberry
Auto-Discovery Enable mDNS automatic PI-Star detection

8. Advanced Features

Country Flag Backgrounds

During an active DMR transmission, a country flag matching the operator's registered country is drawn as a faint background behind the callsign zone. Flags are rendered directly on the display using coloured rectangles — no image files are needed. Over 100 countries are supported, covering the vast majority of DMR operators worldwide. The flag fades naturally into the zone colour, keeping the callsign clearly readable at all times.

Smart Location Display

The location bar shows as much detail as available from the database. Where city, state and country are all present they are displayed together (e.g., "Leeds, Yorkshire, U.K."). Where only some fields are available the device formats them gracefully. Long location strings scroll smoothly with a 2-second pause at the start so you can read the beginning before it moves.

Automatic Brightness

The device can adjust display brightness automatically based on whether it is day or night at your location, reducing glare in a darkened shack at night. Sunrise and sunset times are calculated from your configured location coordinates. Manual override is always available from the options menu.

SD Card DMR Database

A comprehensive DMR database with 450,000+ callsigns is stored on the SD card for easy updates. The optimised indexing system allows millisecond lookups across the entire database without loading it entirely into memory.

mDNS Auto-Discovery

The device can automatically find your PI-Star on the network using mDNS. It searches for: pi-star, pistar, pi-star.local, pistar.local.

Multiple WiFi Profiles

The device stores up to 30 WiFi networks. You can add networks by entering AP Setup Mode and saving additional credentials without losing existing ones. The device remembers the last successfully connected network and tries that first on boot.

Automatic Reconnection

If WiFi connection is lost, tap the bottom grey bar to trigger a manual reconnection attempt.

9. Factory Reset

⚠️ Warning: Factory reset will permanently erase all saved WiFi networks, PI-Star settings, and custom configuration. This cannot be undone.

How to Perform Factory Reset:

  1. Long-press the blue header bar for 3 seconds to open the options menu
  2. Tap the "Factory Reset" button
  3. The screen will turn red and display "RESETTING"
  4. Device will reboot into initial setup mode
  5. Reconnect using the setup instructions in Section 3

11. Technical Information

Hardware

  • Display: 2.8" TFT touchscreen (320×240 resolution)
  • Touch: Capacitive touchscreen controller
  • Storage: SD card (for DMR database)
  • Power: 5V USB-C (minimum 500 mA recommended)
  • WiFi: 2.4 GHz 802.11 b/g/n (5 GHz not supported)
  • Speaker: Onboard speaker (reserved for future use)
  • Battery: Optional single-cell LiPo via JST connector — charges automatically when USB-C is connected

Software

  • Firmware: Custom low-level firmware for maximum performance and security
  • PI-Star: Version 3.4 or newer
  • Database: DMR ID database from RadioID.net in CSV format

Network Specifications

  • Protocols: HTTP, mDNS, DNS, NTP
  • AP Mode: 192.168.4.1 (captive portal)
  • Update Rate: 500 ms (2 updates per second)
  • Discovery: mDNS hostnames (pi-star.local, pistar.local)

Database Specifications

  • Callsigns: 450,000+ entries from RadioID.net
  • Lookup Speed: Millisecond response times
  • Data Fields: Callsign, first name, surname, city, state, country
  • Storage: SD card-based for straightforward field updates

Memory & Storage

  • WiFi Profiles: Stores up to 30 networks
  • Retention: All settings persist across power cycles
  • Battery backup: Optional LiPo battery — polarity must be verified before connecting
